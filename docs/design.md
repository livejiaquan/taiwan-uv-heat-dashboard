# 設計筆記

這份筆記記錄介面的設計取捨：參考了什麼、定了哪些規則、為什麼這樣做。

## 參考與借鏡

| 參考 | 借鏡的部分 |
| --- | --- |
| 中央氣象署紫外線觀測頁 | WHO 五級名稱與色階；沒有資料就留白，不補零 |
| 日本環境省 熱中症予防情報 | 每個風險等級配一句具體動作；今天／明天切換 |
| NWS HeatRisk | 熱風險最高級用洋紅，讓最嚴重的兩級在色相上分得開；依對象給建議 |
| EPA／WHO UV Index | UV 3 以上建議防曬，並以「時段」表達防護建議 |
| Apple 天氣、SunSmart | 大數字加等級名；色階條上用圓點標出目前位置 |
| Yr.no 逐時詳細頁 | 淺色頁面底配白色卡片、1280px 容器、逐時表格的列高與留白節奏 |
| IQAir、weather.com | 內文 16px、次要說明 14px；首屏只放一個最大的數字或結論 |

只借鏡版面比例、資訊架構與設計方法。沒有使用任何他站的圖片、商標、字型或文案，色票也全部自訂。

## 規則

- **首屏只有一個焦點**：結論句（桌面 64px、手機 40px，字重 800）。紫外線與體感數值是第二層（28px／18px）。
- **字級階梯**：12 / 14 / 16 / 18 / 22 / 28 / 40 / 64。內文與卡片 16px，次要說明 14px，12px 只用於圖表軸標與時間戳。
- **間距階梯**：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。所有卡片內距相同。
- **單一容器線**：內容寬 1280px，區塊左緣只落在容器線與卡片內緣兩處。
- **卡片**：白底、8px 圓角、無陰影；層次靠頁面底色與 1px 分隔線。
- **顏色只用在資料上**：UV 用 WHO 五級色；體感溫度用中性到暖色，最高級為洋紅。色塊一律附文字或數值，不單靠顏色傳達。
- **觸控目標**至少 44px；文字對比至少 4.5:1。

## 資料時效

資料舊了也照常顯示，只用標示說明資料有多舊（門檻對應排程實際每 3–4 小時才跑一次）：

| 資料時間 | 呈現 |
| --- | --- |
| 90 分鐘內 | 綠點，只顯示資料時間 |
| 6 小時內 | 琥珀色標示 |
| 24 小時內 | 琥珀色標示，加說明與官方連結；結論卡改中性色，數字保留 |
| 超過 24 小時 | 頂部一行說明，結論旁註明「N 天前的資料」 |

連不上時顯示上次成功載入的快照；完全沒有資料時，錯誤卡只佔內容區的一塊，頁首與頁尾保留。年齡由瀏覽器依資料本身的時間計算（`src/lib/freshness.ts`）。

## 圖示與品牌標記

- 所有介面圖示都來自 [Lucide](https://lucide.dev)（MIT），透過 `lucide-react`：24px 格、線寬 1.75、圓角線端、跟隨文字顏色，尺寸只用 16 與 20。
- 品牌標記是 `public/brand/mark.svg`：琥珀色 `#c28a29` 的圓角方形，中間是白色的 Lucide `sun`。`favicon.svg`、`apple-touch-icon.png` 與頁首的標記都由它而來。
- 圖表（體感溫度曲線）與縣市地圖是資料圖形，不屬於圖示。

## 版面結構

地點名稱與資料時間 → 今天／明天 → 結論句 → 指標列（紫外線、體感、需要防曬、已知最高體感、適合運動）→「表格／圖表」切換 → 逐時表格 → 出門清單與曬紅時間估算 → 分對象建議 → 全台比較（地圖與排序清單）→ 資料來源與聲明。
